# Lucent Video: fast Usenet reader test (Android, Kodi 21)

Test files only. Nothing here is in the Kodi repository, and nobody gets them as an update.

1. `vfs.lucent-0.1.0-test4-android-armv7-kodi21.zip`: the fast reader (vfs.lucent) for Kodi 21 on Android, 32-bit.
2. `plugin.video.lucent-1.0.0-beta1-74-test.zip`: Lucent Video update 74, which hands Usenet films to that reader.

Install both with *Settings > Add-ons > Install from zip file*, vfs.lucent first.

vfs.lucent is licensed under GPL-2.0-or-later and is based on vfs.tmdbm by Angelitto. The source is in `vfs.lucent/` on this branch.
